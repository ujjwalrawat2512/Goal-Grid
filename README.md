# ⚽ GoalGrid — Live Football Scores & Analytics

**GoalGrid** is a modern, responsive football dashboard designed for real-time match tracking, league standings, fixture results, and curated football news. Built with React 19, TypeScript, and Tailwind CSS v4.

---

## 🔥 Features

- ⚡ **Live Scoreboard**: Real-time match status and live ticker updates.
- 📊 **Standings & Tables**: Up-to-date league tables with points, goal difference, and team form.
- 📰 **Football News & Articles**: Latest transfer news, match reports, and analysis.
- 🎯 **Match Results & Fixtures**: Comprehensive list of past results and upcoming fixtures.
- 🎨 **Modern Dark UI**: High-contrast, clean sports analytics dashboard interface.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, React Router DOM v7
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Build Tool**: Vite 8
- **Formatting**: oxfmt
